# 🎯 ПОЛНАЯ КАРТА: ActEditor vs ActFormPage

## Сравнительная таблица

| Функция | ActEditor.tsx | ActFormPage.tsx |
|---------|---|---|
| **Назначение** | Просмотр акта в списке | Создание/редактирование акта |
| **Вкладка 1** | Просмотр основных данных | ✏️ Редактирование основных данных |
| **Вкладка 2** | 🔍 Read-only карточки распределения | ✏️ Полное редактирование с договорами и **КРЕАТИВАМИ** |
| **Вкладка 3** | 🔍 Read-only таблица статистики | ✏️ Редактирование + 🔄 **Автоперенос из VK ORD** |
| **Где используется** | На странице `/acts` (в ActsPage) | На странице `/acts/new` или `/acts/{id}/edit` |
| **Вид** | Inline компонент в списке | Отдельная полная страница |

## ДЕТАЛЬНО: ЧТО НА СКРИНШОТЕ vs РЕАЛЬНОСТЬ

### На скриншоте (ActEditor.tsx):

```
┌─ ОСНОВНЫЕ ДАННЫЕ ─────────────────────────────────────┐
│ [Номер]         [Договор ▼]                           │
│ [Сумма]         [НДС %]    [НДС сумма] (read-only)    │
│ [Дата начала]   [Дата конца]   [Дата выставления]     │
│ [Дата оплаты]                                         │
└───────────────────────────────────────────────────────┘

┌─ РАСПРЕДЕЛЕНИЕ ───────────────────────────────────────┐
│ Распределение #1 (только просмотр)                    │
│ ├─ Договор: ХХХ (статика)                             │
│ ├─ Сумма: ХХХ ₽ (статика)                             │
│ ├─ НДС: ХХХ % (статика)                               │
│ └─ Креативы: 0 шт (статика) ❌ НЕЛЬЗЯ ДОБАВИТЬ       │
└───────────────────────────────────────────────────────┘

┌─ СТАТИСТИКА ──────────────────────────────────────────┐
│ Таблица метрик (только просмотр)                      │
│ ├─ Метрика: ХХХ (статика)                             │
│ ├─ Значение: ХХХ (статика)                            │
│ └─ ... (все в режиме чтения) ❌ НЕЛЬЗЯ ЗАГРУЗИТЬ      │
└───────────────────────────────────────────────────────┘
```

### РЕАЛЬНОСТЬ: В ActFormPage.tsx:

```
┌─ ОСНОВНЫЕ ДАННЫЕ ─────────────────────────────────────┐
│ [Номер ▼]       [Договор ▼]                           │
│ [Сумма ✏️]       [НДС % ✏️]    [НДС ✏️] (авто)        │
│ [Дата ✏️]        [Дата ✏️]   [Дата ✏️]                │
│ [Дата ✏️]                                             │
└───────────────────────────────────────────────────────┘

┌─ РАСПРЕДЕЛЕНИЕ ───────────────────────────────────────┐
│ [+ Добавить договор]                                  │
│ Распределение #1 (РЕДАКТИРУЕМО!)              [-]    │
│ ├─ [Договор ▼ ✏️]  [Креативы ✏️ (выбери сколько!)   │
│ ├─ [Сумма ✏️]  [НДС % ✏️]  [НДС ✏️] (авто)           │
│ └─ [Описание ✏️]                                      │
│                                                      │
│ Итого: XXX ₽                                        │
└───────────────────────────────────────────────────────┘

┌─ СТАТИСТИКА ──────────────────────────────────────────┐
│ [🔄 Подтянуть из VK ORD]  [+ Добавить метрику]       │
│                                                      │
│ Таблица метрик (РЕДАКТИРУЕМО!)                       │
│ ├─ [Метрика ✏️]  [Значение ✏️]  [Единица ✏️]  [...]  │
│ ├─ [Метрика ✏️]  [Значение ✏️]  [Единица ✏️]  [...]  │
│ └─ ... [+ Добавить еще]                             │
└───────────────────────────────────────────────────────┘
```

## ГЛАВНОЕ ОТЛИЧИЕ: КРЕАТИВЫ

### ActEditor (скриншот):
```
Креативы: 5 шт. (показано как статика)
```
❌ Нельзя изменить  
❌ Нельзя добавить  
❌ Нельзя удалить  

### ActFormPage (РЕАЛЬНАЯ форма):
```
[Креативы ▼] ← Autocomplete с множественным выбором
├─ ✅ ERID-12345 ✕
├─ ✅ ERID-67890 ✕
├─ ✅ ERID-11111 ✕
└─ + Добавить еще
```
✅ Можно выбрать несколько  
✅ Можно удалить каждый  
✅ Можно добавить еще  

---

## ГЛАВНОЕ ОТЛИЧИЕ: АВТОПЕРЕНОСЫ (Статистика)

### ActEditor (скриншот):
```
Таблица фиксированная (read-only)
```
❌ Нельзя загрузить из VK ORD  
❌ Нельзя добавить метрику  
❌ Нельзя редактировать  

### ActFormPage (РЕАЛЬНАЯ форма):
```
[🔄 Подтянуть из VK ORD] ← АВТОМАТИЧЕСКАЯ ЗАГРУЗКА!
     ↓
Система автоматически заполняет таблицу метриками
из API VK ORD

+ [Добавить метрику] ← РУЧНОЕ ДОБАВЛЕНИЕ
     ↓
Можно добавить свои метрики вручную
```

✅ Автоматическая загрузка из VK ORD  
✅ Ручное добавление метрик  
✅ Редактирование каждой метрики  
✅ Удаление метрик

## КАК ПЕРЕЙТИ К АКТУАЛЬНОЙ ФОРМЕ?

```
Вы смотрите на: /acts (ActsPage + ActEditor)
                     ↓
Нужно перейти на:  /acts/new (ActFormPage)
                или /acts/{id}/edit (ActFormPage)
                     ↓
Нажать "+ Создать новый акт"
                     ↓
Выбрать клиента, контрактора, договор
                     ↓
ОТКРОЕТСЯ ПОЛНАЯ ФОРМА ActFormPage
```
