# VK Components Registry

Этот реестр содержит кастомные компоненты UI для проектов VK ОРД.

## Доступные компоненты

### @vk/vk-custom-select
Кастомный селект компонент с поддержкой мультиселекта.
```bash
npx shadcn@latest add @vk/vk-custom-select
```

### @vk/vk-file-uploader
Компонент для загрузки файлов с drag & drop поддержкой.
```bash
npx shadcn@latest add @vk/vk-file-uploader
```

### @vk/vk-party-selector
Компонент для выбора сторон договора с поиском и валидацией.
```bash
npx shadcn@latest add @vk/vk-party-selector
```

## Настройка локального сервера реестра

Для работы с реестром запустите локальный HTTP сервер:

```bash
npx http-server ./registry -p 8080 --cors
```

## MCP Server для Cursor

MCP (Model Context Protocol) сервер для shadcn/ui позволяет AI ассистентам взаимодействовать с реестрами компонентов.

### Что может MCP сервер:

- Просматривать доступные компоненты в реестрах
- Автоматически добавлять компоненты в проект
- Устанавливать необходимые зависимости
- Создавать компоненты на основе реестров

### Настройка в Cursor:

1. MCP сервер автоматически настроен в `.cursor/mcp.json`
2. Перезапустите Cursor для применения настроек
3. Теперь AI может работать с компонентами через MCP

### Примеры использования в Cursor:

- "Добавь vk-custom-select компонент"
- "Создай форму с vk-party-selector"
- "Покажи доступные компоненты в vk реестре"

## Структура реестра

Каждый компонент имеет отдельный JSON файл с:
- `$schema` - ссылка на схему shadcn/ui
- `name` - уникальное имя компонента
- `type` - тип (`registry:ui` для UI компонентов)
- `title` - человекопонятное название
- `description` - описание компонента
- `dependencies` - необходимые зависимости
- `files` - массив файлов компонента

## Добавление новых компонентов

1. Создайте JSON файл в папке `registry/`
2. Следуйте схеме `https://ui.shadcn.com/schema/registry-item.json`
3. Перезапустите HTTP сервер
4. Протестируйте добавление компонента

## Развертывание реестра

Для публичного использования разместите файлы реестра на любом HTTP сервере и обновите URL в `components.json`.
