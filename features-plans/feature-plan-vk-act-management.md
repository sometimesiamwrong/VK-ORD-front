# План реализации фичи: vk-act-management

Описание фичи:
Новая страница «Акты», где пользователь может выбрать компанию (рекламодателя или исполнителя), увидеть связанные с компанией акты, создать новый акт или отредактировать существующий, выбрать договор из выпадающего списка, просмотреть и выбрать креативы, подтянуть статистику и подготовить данные для отправки в VK ORD API. На первом этапе используем моковые данные с унифицированным контрактом и креативами, затем переключаемся на боевой API.

---

## Вводные вопросы для пользователя
- [x] Какова основная задача/цель фичи? — Сократить время подготовки актов для VK ORD за счёт единой страницы создания/редактирования актов с автоподгрузкой договоров, креативов и статистики.
- [x] Какой предполагаемый пользователь фичи? — Аккаунт-менеджеры и специалисты по документообороту агентства, работающие с VK ORD.
- [x] Какие основные сценарии использования? — 1) Найти компанию, 2) Просмотреть список актов и создать новый, 3) Заполнить реквизиты акта, выбрать договор, подтянуть креативы и статистику, 4) Отправить акт в VK ORD и отслеживать статус.
- [x] Нужен ли доступ/регистрация или какие-то права? — Требуется авторизованный пользователь с актуальными VK ORD credential ID и выбранной средой; доступ по роли аналогичной существующим разделам «Договоры/Креативы».
- [x] Какие дополнительные условия или пожелания по интерфейсу? — Сделать интерфейс компактнее, чем в VK ORD, с пошаговой навигацией, автоматическими подсказками по НДС и суммам, возможностью быстрого переключения между актами компании и сохранением черновиков.

### Детализация макета и взаимодействий

**Общий лейаут**

- Верхняя панель (sticky) на всю ширину: название компании/акта, дропдаун выбора действующего credential, статусы и CTA-кнопки `Сохранить черновик`, `Отправить в VK ORD`, `Экспорт PDF`, `Удалить`. Кнопки активируются/деактивируются по состояниям `isDirty`, `isSubmitting`, `status !== draft`.
- Основное тело разбито на две колонки (70% левая «рабочая зона», 30% правая «контекст»). На ширине < 1024px блоки переключаются в вертикальный стек с collapsible секциями.
- Правая колонка содержит `ActHintsSidebar`: карточки подсказок, расшифровка полей, таймлайн действий и блок «Последние действия».

**Зона поиска и выбора сущностей (левая колонка, верх)**

1. `CompanyLookup`
  - Поле ввода с авто-комплитом и подсказками по ИНН, названию, внешнему ID.
  - Кнопка `Найти` (для клавиатуры) и иконка `Очистить`.
  - Тоггл `Показывать только мои компании`.
  - Состояния: `loading` (спиннер внутри поля), `empty` (плашка «Компания не найдена»), `error` (toast + сообщение под полем).
  - По выбору компании открывается ее карточка: название, ИНН, кнопка `Открыть в CRM` и счетчик актов.

2. `ActListPanel`
  - Хедер с фильтрами: селект `Статус` (все, черновик, отправлен, ошибка), датапикеры `Период с/по`.
  - Таблица/лист актов с колонками `Номер`, `Дата`, `Сумма`, `Статус`, `Договор`, CTA `Открыть`.
  - Кнопки `Создать акт`, `Импорт из XLSX` (пока disabled, подсказка про roadmap).
  - Пагинация `prev/next`, количество на странице.
  - Карточка акта при клике раскрывается справа в форме или загружает данные в `ActEditor`.

**Форма акта `ActEditor` (левая колонка, ниже панелей)**

- Наверху табы: `Основные данные`, `Распределение`, `Статистика`. На мобилке — stepper с кнопками «Далее/Назад».
- Sticky summary-панель под табами: отображает текущую сумму, НДС, статус; содержит чекбокс `Рассчитать суммы автоматически`.

Таб "Основные данные":

- Поля ввода:
  - `Номер акта` (input + подсказка `Можно оставить пустым, если номер будет присвоен автоматически`).
  - `Договор` (комбо-бокс с поиском по номеру/названию, отображает последние использованные).
  - `Роль заказчика`, `Роль исполнителя` (select с заранее подгруженными значениями).
  - `Сумма, ₽` и `Ставка НДС, %` (маскированные numeric inputs, inline валидация, автопересчет полей «Сумма НДС» и «Сумма без НДС»).
  - Блок дат: `Дата начала периода`, `Дата окончания`, `Дата выставления`, `Дата оплаты` (дополнительно), каждый с календарем и быстроселектом «текущий месяц».
  - `Посреднический договор` (select + чекбокс `Нет посредника`).
  - Чекбокс `Рассчитать автоматически` (переключает disabled state полей НДС, показывает tooltip с формулой).
- Интерактивные элементы: иконка инфо возле каждого поля с подсказкой, кнопка `Заполнить из шаблона` (открывает модалку с выбором сохраненных пресетов).

Таб "Распределение":

- Секция `Исходный договор`: селект договора, поле суммы, ставка НДС, чекбокс автоподсчета — аналогичные виджеты, но с возможностью добавить несколько блоков через `Добавить договор` (динамический список).
- Для каждого договора — блок `Креативы`:
  - `CreativeSelect`: мультиселект с поиском, тегами и кнопкой `Показать все креативы`.
  - Кнопка `Добавить статистику по креативу` — формирует карточку в табе "Статистика" с предварительно заполненными фильтрами.
  - Кнопка удаления креатива (`Удалить`).
- Summary снизу: `Общая сумма распределения`, `Несовпадение с суммой акта` (warning, если расхождение > 1 руб.).

Таб "Статистика":

- Коллекция карточек статистики: каждая содержит селект периода (пресеты "Неделя", "Месяц"), фильтр по площадке, чекбокс `Использовать валидированные данные`, таблицу `Метрика/Значение` (редактируемые ячейки).
- Кнопка `Подтянуть из VK ORD` (вызывает API или mock). Состояния: `loading` (скелетоны), `partial` (если некоторые креативы без статистики — выводить инфо-блок).
- Кнопка `Добавить произвольную метрику` — открывает модальное окно с полями `Название`, `Значение`, `Единицы`.
- Тумблер `Закрепить стат. блок` — фиксирует карточку вверху списка.

**Правая колонка `ActHintsSidebar`**

- Карточка «Проверочный лист» — чекбоксы: `Заполнены суммы`, `Проверены даты`, `Приложены документы`.
- Блок «История изменений» — вертикальный таймлайн с аватарками и действиями (создан, отправлен, ошибка).
- Инфо-блок «Требования VK» — collapsible с текстом.
- Quick-actions: кнопка `Создать связанный акт`, `Скопировать реквизиты клиента`.

**Основные сценарии взаимодействия**

1. **Поиск компании ➜ выбор акта ➜ редактирование**
  - Пользователь вводит ИНН, выбирает компанию, видит автоматически отфильтрованные акты. Клик по акту загружает данные в форму, подсвечивает активный элемент в списке, отображает историю в сайдбаре.

2. **Создание нового акта**
  - Кнопка `Создать акт` открывает пустую форму с предзаполненными полями (текущий период, компания). Focus ставится на `Договор`. Sticky панель показывает `Черновик не сохранён`. При вводе — отображается баттон `Сохранить черновик`.

3. **Подбор договора и креативов**
  - После выбора `Договор` триггерится загрузка креативов (лоадер рядом с селектом). Креативы добавляются через теговый мультиселект; пользователь может раскрыть подробности креатива (кнопка-иконка «i», открывает drawer).

4. **Работа со статистикой**
  - Кнопка `Подтянуть из VK ORD` делает запрос с выбранными договором/креативами и диапазоном дат. Пока данные грузятся — карточки показывают skeleton. После загрузки пользователь может вручную править ячейки, при изменении выводится бейдж `Изменено вручную`.

5. **Отправка**
  - При клике `Отправить в VK ORD` запускается валидация. Ошибочные поля подсвечиваются, в сайдбар выводится список ошибок, в шапке появляется alert. Успешная отправка меняет статус акта и скрывает кнопку `Удалить`.

**Состояния и подсказки**

- Loader-индикаторы в каждом секционном блоке (`Skeleton` + progress bar в шапке).
- Inline errors под полями, глобальные ошибки — в toast.
- Tooltip с формулой НДС, подсказки по авторасчету.
- Empty states с CTA: «Нет актов — создайте первый», «Нет статистики — попробуйте обновить период».
