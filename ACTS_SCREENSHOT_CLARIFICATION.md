# ⚠️ ВАЖНО: Что вы видите на скриншоте

## На скриншоте показано редактирование СУЩЕСТВУЮЩЕГО акта

Компонент: `ActEditor.tsx`  
Это **упрощенный просмотр**, а не полная форма создания!

---

## Проблема на скриншоте:

Вы видите три вкладки:
- **ОСНОВНЫЕ ДАННЫЕ** - поля для редактирования
- **РАСПРЕДЕЛЕНИЕ** - только просмотр (read-only карточки)
- **СТАТИСТИКА** - только таблица (read-only)

### Почему не видно добавления креативов и договоров?

Потому что `ActEditor.tsx` - это **упрощенный компонент** для просмотра существующего акта в контексте списка актов. 

Полная функциональность находится в `ActFormPage.tsx`!

---

## Где РЕАЛЬНО добавлять креативы и автопереносы?

**Файл**: `src/features/acts/ActFormPage.tsx`

**Вкладка 2: РАСПРЕДЕЛЕНИЕ** содержит:
1. ✏️ **Договоры** - Autocomplete для выбора
2. ✏️ **Креативы** - Autocomplete с **МНОЖЕСТВЕННЫМ выбором** 
   - Каждое распределение может иметь ≤ несколько креативов
   - Выбранные креативы показаны как чипсы
3. ✏️ **Сумма, НДС** - редактируемые поля
4. ✏️ **Описание** - текстовое поле

**Вкладка 3: СТАТИСТИКА** содержит:
- 🔄 Кнопка "Подтянуть из VK ORD" (автопереносы данных)
- ➕ Добавление метрик вручную
- Редактируемая таблица метрик

---

## ПРАВИЛЬНЫЙ ПУТЬ СОЗДАНИЯ АКТА

```
1. Нажать "+ Создать новый акт" на странице /acts
       ↓
2. Выбрать клиента → контрактора → договор в ActCreationFlow
       ↓
3. Откроется ПОЛНАЯ форма ActFormPage.tsx
       ↓
4. Вкладка 1: Заполнить основные данные
       ↓
5. Вкладка 2: Добавить распределения с договорами и КРЕАТИВАМИ
       ↓
6. Вкладка 3: Добавить статистику (автоматически из VK ORD)
       ↓
7. Сохранить или отправить
```

---

## Краткая справка по файлам

| Файл | Назначение | Функции |
|------|-----------|---------|
| `ActFormPage.tsx` | **СОЗДАНИЕ и полное редактирование** | ✏️ Все функции, включая креативы и автопереносы |
| `ActEditor.tsx` | Просмотр в контексте списка | 🔍 Только просмотр основных данных |
| `ActCreationFlow.tsx` | Начальный поток выбора | Выбор клиент → контрактор → договор |
| `ActsPage.tsx` | Главная страница управления актами | Поиск, список, быстрые действия |
