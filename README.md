# VK ОРД Frontend Wrapper

Веб-приложение для маркировки рекламы в системе VK ОРД (Обязательная Регистрация Данных).

## Описание

Приложение предоставляет удобный интерфейс для создания и управления рекламными материалами в системе VK ОРД. Поддерживает полный цикл работы с контрагентами, договорами, креативами и получением ERID кодов.

## Архитектура

Проект построен по современным принципам веб-разработки с использованием лучших практик:

### Структура проекта

```
src/
├── components/          # React компоненты
│   ├── ui/             # Переиспользуемые UI компоненты
│   ├── steps/          # Шаги визарда
│   └── wizard/         # Основной компонент визарда
├── context/            # React Context для глобального состояния
├── hooks/              # Кастомные React хуки
├── services/           # API сервисы
├── types/              # TypeScript типы
├── utils/              # Вспомогательные функции
├── constants/          # Константы и конфигурации
└── styles/             # Стили приложения
```

### Ключевые принципы

- **Компонентная архитектура**: Разделение на маленькие, переиспользуемые компоненты
- **Слоистая архитектура**: Четкое разделение ответственности между слоями
- **TypeScript**: Полная типизация для надежности и лучшей DX
- **React Hooks**: Современный подход к управлению состоянием
- **Context API**: Глобальное состояние приложения
- **Кастомные хуки**: Инкапсуляция бизнес-логики

### Основные компоненты

- **Wizard**: Главный компонент, управляющий потоком приложения
- **Step1-4**: Компоненты отдельных шагов визарда
- **UI Components**: Переиспользуемые элементы интерфейса (CustomSelect, TagSelector, etc.)
- **Context**: Централизованное управление состоянием
- **Hooks**: Логика работы с API, файлами, валидацией

## Установка и запуск

```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run dev

# Сборка для продакшена
npm run build

# Предпросмотр сборки
npm run preview
```

## Скрипты

- `npm run dev` - запуск сервера разработки
- `npm run build` - сборка для продакшена
- `npm run preview` - предпросмотр собранного приложения
- `npm run mcp:ts-dev` - запуск TypeScript helper для MCP

## API

Приложение взаимодействует с VK ОРД API через настроенный бэкенд. Поддерживаются следующие операции:

- Поиск контрагентов по ИНН
- Создание контрагентов
- Создание договоров
- Создание креативов
- Получение ERID кодов
- AI-подбор ККТУ кодов

## Разработка

### Добавление новых компонентов

1. Создайте компонент в соответствующей папке (`components/ui/`, `components/steps/`)
2. Добавьте экспорт в `index.ts` папки
3. Используйте TypeScript для типизации пропсов

### Работа с состоянием

Используйте Context API через `useApp()` хук для доступа к глобальному состоянию:

```typescript
const { wizardState, setStep, setMessage } = useApp()
```

### Создание кастомных хуков

Размещайте бизнес-логику в кастомных хуках в папке `hooks/`:

```typescript
export const useMyFeature = () => {
  // Логика хука
}
```
