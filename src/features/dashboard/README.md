# Фича: Главная панель (Dashboard)

## Описание

Главная страница приложения после входа. Предоставляет обзор системы, быстрый доступ к основным разделам и информацию о текущем пользователе.

## Основные компоненты

### DashboardPage (`DashboardPage.tsx`)

**Назначение:** Центральная страница приложения с навигацией по всем модулям

**Структура страницы:**

1. **Приветственная секция**
   - Персонализированное приветствие с именем пользователя
   - Краткое описание возможностей системы

2. **Быстрые действия**
   - Карточки с основными разделами приложения
   - Иконки и описания для каждого раздела
   - Кнопки быстрого перехода

3. **Недавняя активность** (placeholder)
   - Секция для отображения последних действий пользователя
   - Пока что только placeholder

## Быстрые действия

### 1. Контракты
- **Иконка:** 📄 Description
- **Описание:** Создание и управление контрактами
- **Переход:** `/contracts`
- **Цвет:** Primary (синий)

### 2. Креативы
- **Иконка:** 🎬 Movie
- **Описание:** Создание и управление креативами
- **Переход:** `/creatives`
- **Цвет:** Secondary (фиолетовый)

### 3. Медиа
- **Иконка:** 🖼️ Image
- **Описание:** Загрузка и управление медиафайлами
- **Переход:** `/media`
- **Цвет:** Success (зеленый)

### 4. Credentials
- **Иконка:** 🔑 VpnKey
- **Описание:** Управление VK ORD токенами
- **Переход:** `/credentials`
- **Цвет:** Warning (оранжевый)

## UI Компоненты

**Material UI:**
- Typography - заголовки и текст
- Paper - приветственная секция

**shadcn/ui:**

## Интеграция с профилем

### useUserProfile()

Хук получает данные текущего пользователя из API `/api/users/me`:

```typescript
interface UserProfile {
  id: string
  userName: string
  name?: string
  isActive: boolean
  createdAt: string
  updatedAt: string
}
```

**Использование:**
- Отображение имени пользователя в приветствии
- Персонализация интерфейса

**Состояния:**
- `isLoading` - показывает загрузку
- `error` - обработка ошибок
- `data` - профиль пользователя

## Layout

Страница обернута в `DashboardLayout`, который включает:
- Навигационная панель (AppBar)
- Боковое меню (Drawer)
- Переключатель окружения (Sandbox/Production)
- Кнопка выхода

## Навигация

**Маршрут:** `/dashboard`

**Доступ:** Защищенный маршрут (требуется аутентификация)

**Переходы:**
- `/contracts` - Управление контрактами
- `/creatives` - Управление креативами
- `/media` - Управление медиафайлами
- `/credentials` - Управление токенами
- `/parties` - Управление контрагентами (через меню)
- `/acts` - Управление актами (через меню)
- `/wizard` - Мастер получения ERID (через меню)
- `/profile` - Профиль пользователя (через меню)

## Адаптивность

**Tablet (md):**
- 2 карточки в ряд

**Mobile (xs):**

## Особенности реализации

1. **Консоль логирование:**
   - Логируется состояние загрузки профиля
   - Полезно для дебаггинга

2. **Автоматическая загрузка:**
   - Профиль загружается автоматически при монтировании
   - Использует React Query cache

3. **Responsive grid:**
   - `gridTemplateColumns: 'repeat(auto-fit, minmax(280px, 1fr))'`
   - Автоматическое распределение карточек

4. **Иконки Material UI:**
   - Размер: 40px
   - Цвета: соответствуют теме (primary, secondary, success, warning)
