# Фича: Управление контрагентами (Parties/Counterparties)

## Описание

Модуль работы с контрагентами (клиенты, подрядчики, агентства, издатели) VK ORD. Позволяет искать контрагентов по ИНН через сервис DaData, создавать их в системе VK ORD с указанием ролей, просматривать полную информацию.

## Основные компоненты

### PartiesPage (`PartiesPage.tsx`)

**Назначение:** Страница для поиска и создания контрагентов в VK ORD

**Функциональность:**
1. **Поиск контрагента** по ИНН через DaData
2. **Отображение информации** о найденной организации
3. **Создание контрагента** в VK ORD с выбором ролей
4. **Валидация ИНН** (10 или 12 цифр)

## Структура страницы

Двухколоночный layout (адаптивный):

1. **Поиск контрагента** (левая панель)
   - Форма ввода ИНН
   - Кнопка "Найти контрагента"
   - Карточка с результатами поиска

2. **Создать контрагента в VK ОРД** (правая панель)
   - Поле ввода ИНН
   - Мультивыбор ролей (Select multiple)
   - Кнопка "Создать контрагента"

## API запросы

### Поиск по ИНН (DaData)
```
GET /api/parties/lookup?inn={inn}
```

**Ответ:** `DaDataPartyShortResponse`

### Создание контрагента в VK ORD
```
POST /api/parties/set
Body: { inn, types }
```

**Ответ:** Созданный контрагент (детали зависят от API)

## Функциональность

### 1. Поиск контрагента

**Процесс:**
1. Ввести ИНН (10 или 12 цифр, разрешены только цифры)
2. Нажать "Найти контрагента"
3. Валидация: длина ИНН должна быть 10 или 12
4. Запрос в DaData API
5. Отображение результатов в карточке

**Отображаемые данные:**
- ИНН
- Полное наименование (`name.full`)
- Краткое наименование (`name.shortWithOpf`)
- Наименование (строка, если `name` не объект)
- КПП (если есть)
- Тип (если есть)

**Обработка:**
- Успех → `toast.success('Контрагент найден')` + заполнение карточки
- Ошибка → `toast.error('Ошибка при поиске контрагента')` + очистка карточки
- Валидация → `toast.error('ИНН должен содержать 10 или 12 цифр')`

### 2. Создание контрагента в VK ОРД

**Процесс:**
1. Ввести ИНН (10 или 12 цифр)
2. Выбрать одну или несколько ролей (advertiser, agency, publisher)
3. Нажать "Создать контрагента"
4. Валидация:
   - ИНН 10 или 12 цифр
   - Выбрана хотя бы одна роль
5. Запрос в VK ORD API
6. Успех → toast + очистка формы

**Выбор ролей:**
- Multiple Select с Chips для отображения выбранных
- `renderValue` показывает Chips с русскими названиями

**Обработка:**
- Успех → `toast.success('Контрагент успешно создан')` + очистка формы
- Ошибка → `toast.error(getErrorMessage(error))` с детальным сообщением
- Валидация → toast с описанием проблемы

## Валидация ИНН

### Фильтрация ввода
```typescript
onChange={(e) => setInn(e.target.value.replace(/\D/g, ''))}
```
Разрешены только цифры (`\D` - не цифра).

### Проверка длины
```typescript
if (inn.length !== 10 && inn.length !== 12) {
  toast.error('ИНН должен содержать 10 или 12 цифр')
  return
}
```

### Ограничение maxLength
```typescript
inputProps={{ maxLength: 12 }}
```

## Роли контрагентов

### Advertiser (Рекламодатель)
Компания, которая заказывает рекламу.

### Agency (Рекламное агентство)
Компания-посредник между рекламодателем и издателем.

### Publisher (Издатель)
Компания, которая размещает рекламу на своих площадках.

### ORS (Оператор рекламной системы)
Не включен в список на странице, но поддерживается системой.

## Интеграция с DaData

**DaData** - внешний сервис предоставления информации о российских компаниях:
- Поиск по ИНН
- Возврат полной информации (название, адрес, статус, и т.д.)
- Используется для автозаполнения данных

**Backend интеграция:**
- Запросы к DaData проксируются через backend
- Кеширование и rate-limiting на стороне сервера

## Особенности реализации

1. **Нормализация данных:**
   - `name` может быть строкой или объектом
   - Проверка типа перед отображением полей

2. **Мультивыбор ролей:**
   - `SelectChangeEvent<string[]>` тип для обработчика
   - `renderValue` для кастомного отображения Chips

3. **Очистка формы:**
   - После успешного создания контрагента форма сбрасывается
   - После ошибки поиска карточка очищается

4. **Валидация на клиенте:**
   - Разрешены только цифры
   - Проверка длины перед отправкой
   - Проверка наличия ролей

5. **Toast notifications:**
   - Успех: зеленый
   - Ошибка: красный
   - Информация: синий
