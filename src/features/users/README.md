# Фича: Профиль пользователя (Users/Profile)

## Описание

Модуль управления профилем пользователя. Позволяет просматривать и редактировать личную информацию, отображает статистику аккаунта и информацию о подписке.

## Основные компоненты

### ProfilePage (`ProfilePage.tsx`)

**Назначение:** Страница профиля пользователя с возможностью редактирования

**Структура страницы:**

1. **Личная информация**
   - Имя пользователя (только чтение)
   - Отображаемое имя (редактируемое)
   - Статус аккаунта
   - Дата регистрации
   - Дата последнего обновления

2. **Статистика аккаунта**
   - Текущий статус (Активен/Неактивен)
   - Дата регистрации
   - Количество дней с регистрации

3. **Информация о подписке**
   - Тип подписки (Безлимитная)
   - Начало подписки
   - Статус подписки
   - Срок действия (Бессрочно)

4. **Недавняя активность**
   - Быстрая кнопка перехода в wizard для получения ERID

## Функциональность

### Режимы работы

**Режим просмотра (по умолчанию):**
- Все поля disabled
- Кнопка "Редактировать"
- Отображение текущих данных

**Режим редактирования:**
- Поле "Отображаемое имя" доступно для изменения
- Кнопки "Сохранить" и "Отмена"
- Валидация данных

### Редактируемые поля

- **Отображаемое имя (name)** - единственное редактируемое поле
  - Опционально
  - Используется для персонализации интерфейса

### Нередактируемые поля

- **Имя пользователя (userName)** - уникальный идентификатор, не меняется
- **Статус аккаунта (isActive)** - управляется системой
- **Дата регистрации (createdAt)** - устанавливается при регистрации
- **Дата обновления (updatedAt)** - обновляется автоматически

## API Hooks

Хуки определены в `src/auth/hooks.ts`:

### useUserProfile()

Получает данные профиля текущего пользователя.

**Query Key:** `['users', 'me']`

**Endpoint:** `GET /api/users/me`

**Response:**
```typescript
interface UserProfile {
  id: string
  userName: string
  name?: string
  isActive: boolean
  createdAt: string
  updatedAt: string
}
```

**Состояния:**
- `isLoading` - загрузка данных
- `error` - ошибка загрузки
- `data` - данные профиля
- `refetch` - функция для перезагрузки

### useUpdateUserProfile()

Обновляет данные профиля пользователя.

**Mutation Function:** `PUT /api/users/me`

**Request Body:**
```typescript
interface UpdateUserProfileRequest {
  name?: string
}
```

**Поведение:**
- Успех: выход из режима редактирования + refetch данных
- Ошибка: отображение ошибки в Alert

## Обработка ошибок

### Состояние загрузки
```tsx
if (isLoading) {
  return <Typography>Загрузка профиля...</Typography>
}
```

### Ошибка загрузки
```tsx
if (error) {
  return (
    <Alert severity="error">
      Ошибка загрузки профиля: {error.message}
    </Alert>
  )
}
```

### Профиль не найден
```tsx
if (!profile) {
  return (
    <Alert severity="warning">
      Профиль не найден
    </Alert>
  )
}
```

## Управление состоянием формы

### Локальное состояние
```typescript
const [editMode, setEditMode] = useState(false)
const [formData, setFormData] = useState({ name: '' })
```

### Синхронизация с профилем
```typescript
useEffect(() => {
  if (profile) {
    setFormData({ name: profile.name || '' })
  }
}, [profile])
```

### Обработчики

**Начать редактирование:**
```typescript
const handleEdit = () => {
  setEditMode(true)
}
```

**Отменить изменения:**
```typescript
const handleCancel = () => {
  setEditMode(false)
  if (profile) {
    setFormData({ name: profile.name || '' })
  }
}
```

**Сохранить изменения:**
```typescript
const handleSave = () => {
  updateProfileMutation.mutate(formData, {
    onSuccess: () => {
      setEditMode(false)
      refetch()
    }
  })
}
```

## API Endpoints

### GET `/api/users/me`
Получить профиль текущего пользователя.

**Headers:**
```
Authorization: Bearer {accessToken}
```

**Response:**
```json
{
  "id": "uuid",
  "user_name": "string",
  "name": "string",
  "is_active": true,
  "created_at": "2024-01-01T00:00:00Z",
  "updated_at": "2024-01-01T00:00:00Z"
}
```

### PUT `/api/users/me`
Обновить профиль текущего пользователя.

**Headers:**
```
Authorization: Bearer {accessToken}
```

**Request Body:**
```json
{
  "name": "string"
}
```

**Response:** Обновленный профиль (аналогично GET)

## Особенности реализации

1. **Автозаполнение формы:**
   - Данные загружаются из профиля при монтировании
   - useEffect следит за изменениями профиля

2. **React Query cache:**
   - Профиль кешируется после первой загрузки
   - refetch() обновляет cache после сохранения

3. **Оптимистичные обновления:**
   - Нет, используется refetch после успешного сохранения
   - Гарантирует актуальность данных

4. **Валидация:**
   - Minimal валидация (поле name опционально)
   - Можно расширить добавлением zod schema

5. **Accessibility:**
   - Все поля имеют labels
   - Disabled состояние четко обозначено
   - Ошибки отображаются в Alert
