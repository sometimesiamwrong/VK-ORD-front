# Фича: Управление медиафайлами (Media)

## Описание

Модуль загрузки и администрирования медиафайлов для VK ORD. Позволяет загружать файлы (изображения, видео, аудио), просматривать информацию по загруженным файлам и удалять медиа при необходимости.

## Основные компоненты

### MediaPage (`MediaPage.tsx`)

**Назначение:** Единая страница для работы с медиафайлами

**Функциональность:**
1. **Загрузка файла** на сервер
2. **Получение информации** о медиа по External ID
3. **Удаление** медиафайла
4. **Предпросмотр** изображений и ссылок

## Структура страницы

Страница разделена на три основные секции:

1. **Загрузка медиафайла**
   - Выбор файла: изображения, видео, аудио (`accept="image/*,video/*,audio/*"`)
   - Отображение информации о выбранном файле
   - Кнопка загрузки

2. **Действия с медиа**
   - Просмотр медиа по `externalId`
   - Удаление медиа по `externalId`

3. **Детали медиа** (появляется после загрузки/поиска)
   - Информация о файле
   - Предпросмотр изображений
   - Ссылка на файл

## Типы данных

### MediaUploadResponse
```typescript
interface MediaUploadResponse {
  externalId: string         // Назначается сервером
  url: string                // Прямая ссылка на файл
  fileName?: string
  fileSize?: number          // Размер в байтах
  mimeType?: string          // MIME тип
}
```

### MediaDetails
```typescript
interface MediaDetails {
  externalId: string
  url: string
  fileName?: string
  fileSize?: number
  mimeType?: string
  uploadedAt?: string
}
```

## API Запросы

### Загрузка медиа
```
POST /api/media/v1/upload
Content-Type: multipart/form-data
Body: FormData { file }
```

**Ответ:** `MediaUploadResponse`

### Получение информации
```
GET /api/media/v1/{externalId}
```

**Ответ:** `MediaDetails`

### Удаление
```
DELETE /api/media/v1/{externalId}
```

**Ответ:** 204 No Content

## Функциональность

### 1. Загрузка файла

**Процесс:**
1. Нажатие на кнопку "Выбрать файл" → открывает системный диалог
2. После выбора - отображается информация:
   - Имя файла
   - Размер (читаемый формат)
   - MIME тип
3. Нажать "Загрузить файл"
4. Успех → toast "Файл успешно загружен"
5. Сохраняется `mediaDetails` с данными ответа

**Преобразование размера:**
```typescript
const formatFileSize = (bytes) => {
  const units = ['Bytes', 'KB', 'MB', 'GB']
  const i = Math.floor(Math.log(bytes) / Math.log(1024))
  return `${(bytes / Math.pow(1024, i)).toFixed(2)} ${units[i]}`
}
```

**Сброс input:**
```typescript
const fileInput = document.getElementById('file-upload') as HTMLInputElement
if (fileInput) fileInput.value = ''
```

### 2. Просмотр медиа

**Процесс:**
1. Ввести `externalId`
2. Нажать "Найти"
3. Отобразится карточка с информацией:
   - External ID
   - URL
   - Имя файла
   - Размер (форматированный)
   - MIME тип
   - Дата загрузки
   - Предпросмотр (если изображение)
   - Кнопка "Открыть файл" (открывает в новой вкладке)

### 3. Удаление медиа

**Процесс:**
1. Ввести `externalId`
2. Нажать "Удалить"
3. Подтверждение через `window.confirm`
4. Успех → toast "Медиафайл успешно удален" + очистка `mediaDetails`

## Состояния UI

### Загрузка
- Кнопки disabled во время запросов (`isPending`)
- Текст "Загрузка..." в кнопке

### Ошибки
- Upload: `uploadMutation.error?.message`
- View: `viewMutation.error?.message`
- Delete: `deleteMutation.error?.message`

### Выбранный файл
- Отображается только до момента загрузки
- После успешной загрузки состояние `selectedFile` сбрасывается

- ExternalId медиа используется для отчетности и актов

## Примеры использования

### Загрузка нового медиа
1. Нажать "Выбрать файл"
2. Выбрать изображение баннера
3. Проверить отображаемые метаданные
4. Нажать "Загрузить файл"
5. Скопировать `External ID` из карточки для дальнейшего использования

### Просмотр загруженного медиа
1. Ввести `externalId`
2. Нажать "Найти"
3. Проверить URL и дату загрузки
4. Нажать "Открыть файл" для проверки в браузере

### Удаление медиа (очистка)
1. Ввести `externalId`
2. Нажать "Удалить"
3. Подтвердить действие
4. Убедиться, что `mediaDetails` очищены

## Особенности реализации

1. **FormData загрузка:** обязательна для отправки файла через Axios
2. **Сбрасывание input:** позволяет повторно выбрать тот же файл
3. **Предпросмотр изображений:** условная проверка `mimeType?.startsWith('image/')`
4. **Toast уведомления:** использование библиотеки `sonner`
5. **Кнопка открытия файла:** `asChild` prop у Button + `<a href target="_blank">`
